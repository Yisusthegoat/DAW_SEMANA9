# Registro de uso de IA

## Alcance real

Codex generó todos los archivos del proyecto a petición del usuario:

- README.md y .gitignore.
- docs/comparacion-php-jsp.md, docs/pruebas-y-evidencias.md y este registro.
- php/lab09/index.html, config.php, procesar.php, resumen.php y assets/styles.css.
- jsp/lab09/index.jsp, procesar.jsp, resumen.jsp, WEB-INF/web.xml y assets/styles.css.
- evidencias/.gitkeep, únicamente para conservar la carpeta vacía.

Esto incluye el diseño, formularios, validaciones, control de métodos, escape HTML, sesiones, redirecciones y configuración mínima de despliegue. Codex también consultó documentación oficial y ejecutó las verificaciones que figuran en pruebas-y-evidencias.md. No se generaron capturas ni se atribuyeron tareas manuales al estudiante.

## Regla de la guía

La guía exige que el **70 % de la lógica de procesamiento y configuración de despliegue se escriba manualmente**. Esta generación completa por IA **no cumple ni demuestra ese porcentaje**. El estudiante debe realizar y documentar su trabajo real conforme a las indicaciones del docente; leer el código generado no equivale a haberlo escrito manualmente.

## Formato requerido

Para documentar ayuda al resolver errores o comparar ciclos de vida, la guía exige:

```text
/* IA: [problema] → Solución manual: [explicación] */
```

Plantilla pendiente de completar con acciones reales, sin presentarla como evidencia:

```text
/* IA: [describir la consulta real] → Solución manual: [explicar lo que efectivamente implementaste o corregiste tú] */
```

No se registran soluciones manuales realizadas por el usuario porque aún no se han aportado. El despliegue JSP, las pruebas visuales y las capturas siguen pendientes según el registro de pruebas.
